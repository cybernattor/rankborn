# Как получить сборку (для тестеров)

Собирать ничего не нужно: APK собирает сервер GitHub, когда владелец проекта запускает сборку (Actions → «Android APK» → Run workflow). Автоматически сборки не идут — минуты Actions ограничены.

1. Войдите на GitHub под своим аккаунтом (владелец проекта должен добавить вас в репозиторий).
2. Откройте страницу релизов: https://github.com/cybernattor/rankborn/releases — сверху самая новая сборка.
3. Скачайте файл `Rankborn-N.apk` (на телефоне — прямо из браузера, где вы вошли в GitHub).
4. Установите. Если Android спросит про «неизвестные источники», разрешите для браузера.
5. Новая сборка ставится поверх старой, данные сохраняются. Если не ставится — удалите старую игру и поставьте заново (так бывает только со сборками до общего ключа проекта).

В игре в паузе включён счётчик FPS и версия сборки видна в названии релиза. Если что-то не так, напишите номер сборки и что делали.

## Если сборка не появилась

Откройте вкладку **Actions** в репозитории: красный крестик — сборка упала (чаще всего упала проверка в `tests/`), откройте её и пришлите лог. Если свежей сборки нет, попросите владельца запустить её.
