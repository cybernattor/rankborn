# Godot MCP (сторонний аддон)

Только для разработки: даёт ИИ-ассистентам доступ к редактору Godot через MCP. В экспорт не попадает (`exclude_filter` в `export_presets.cfg`).

- **Проект**: [godot-mcp-bridge](https://github.com/TomasLucasUTN/godot-mcp-bridge) — автор Tomas Lucas
- **Основа**: форк [tomyud1/godot-mcp](https://github.com/tomyud1/godot-mcp) — автор Tomer Yud
- **Версия в репозитории**: 1.1.6 (в апстриме на момент проверки — 1.3.0)
- **Лицензия**: MIT, текст и copyright — в файле [LICENSE](LICENSE) (не удалять: MIT требует сохранять его)
- В `plugin.cfg` автор указан просто как «Godot MCP» — настоящих авторов искать здесь, не там

Остальной код Rankborn лицензирован иначе (AGPL-3.0, см. корневой `LICENSE`); на этот аддон AGPL не распространяется.
