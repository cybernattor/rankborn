# Rankborn

Strategy, FPS, RP in one time.

## Описание

**Rankborn** — кроссплатформенный РП-шутер с элементами военной стратегии. Живой фронт, где действия каждого игрока — от рядового в окопе до Главнокомандующего — влияют на исход войны.

### Референс: Foxhole
Мета-игра (живой фронт, логистика заводами и грузовиками, строительство траншей и фортификаций, командная иерархия) взята из **Foxhole** — это осознанная основа, а не совпадение. Мы делаем лучше за счёт того, чего в Foxhole нет:
- **FPS-бой вместо изометрии** — стрельба, укрытия и траншеи от первого лица;
- **Модульный конструктор оружия** — армия сама проектирует и утверждает модели, заводы выпускают именно их;
- **Кроссплатформа ПК + мобилки** в одной войне;
- **Явная военная иерархия с обучением** — роли открываются через курсы, а не только через договорённость в чате.

Открытые вопросы, на которые дизайн обязан ответить: как удержать масштаб фронта (Foxhole — сотни игроков на регион) и как сделать логистику от первого лица не скучнее изометрической. Подробно, вместе со справедливостью кроссплея ПК против мобилок, — в [docs/design.md](docs/design.md).

### Ключевые фичи
- Военная иерархия (Командование → Офицеры → Солдаты)
- Физическая логистика (оружие везут грузовиками на фронт)
- Конструктор оружия (модульная сборка из компонентов)
- Инженерные работы (траншеи, деформация меша, фортификации)
- Кроссплатформа (ПК + Мобилки)
- Low-Poly стиль

## Быстрый старт

### Требования
- Godot 4.6+

### Запуск
1. Открой `project.godot` в Godot Editor
2. Нажми F5

### LAN (2-6 игроков)
1. Один игрок жмёт **Создать игру** — лобби само появляется у друзей в списке
2. Остальные выбирают игру в списке (или вводят IP вручную) и подключаются
3. Хост жмёт **Начать матч**
4. Firewall: UDP **7000** (игра) и **7001** (автопоиск) на машине хоста

Локальный тест без второй машины: Debug → Run Multiple Instances = 2.

## Управление

| Действие | ПК | Геймпад | Сенсор |
|---|---|---|---|
| Движение | WASD | Левый стик | Плавающий джойстик слева |
| Обзор | Мышь | Правый стик | Свайп по экрану / по FIRE |
| Огонь | ЛКМ | RT | FIRE (справа и слева) |
| Прицел | ПКМ (удержание или нажатие — в настройках) | LT | AIM (переключатель) |
| Прыжок | Space | A | JUMP |
| Присед | Ctrl / C | B | DUCK (переключатель) |
| Спринт | Shift | L3 | Джойстик до упора вперёд |
| Перезарядка | R | X | R |
| Смена оружия | Колесо | LB / RB | — |
| Меню | Esc | Start | II / «Назад» |

Чувствительность, инверсия Y и режимы прицела/приседа — в меню паузы (сохраняются в `user://settings.cfg`).
