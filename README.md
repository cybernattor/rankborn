# Rankfall

Strategy, FPS, RP in one time.

## Описание

**Rankfall** — кроссплатформенный РП-шутер с элементами военной стратегии. Живой фронт, где действия каждого игрока — от рядового в окопе до Главнокомандующего — влияют на исход войны.

### Ключевые фичи
- Военная иерархия (Командование → Офицеры → Солдаты)
- Физическая логистика (оружие везут грузовиками на фронт)
- Конструктор оружия (модульная сборка из компонентов)
- Инженерные работы (траншеи, деформация меша, фортификации)
- Кроссплатформа (ПК + Мобилки)
- Low-Poly стиль

## Быстрый старт

### Требования
- Godot 4.6+

### Запуск
1. Открой `project.godot` в Godot Editor
2. Нажми F5

### LAN (2-6 игроков)
1. Один игрок жмёт **Создать игру** — в меню появится LAN IP и порт
2. Другие вводят этот IP и жмут **Присоединиться**
3. Хост жмёт **Начать матч**
4. Firewall: разрешить UDP порт **7000** на машине хоста

Локальный тест без второй машины: запусти два инстанса редактора (Debug → Run Multiple Instances = 2).
