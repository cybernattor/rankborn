# Rankborn

Strategy, FPS, RP in one time.

## Описание

**Rankborn** — кроссплатформенный РП-шутер с элементами военной стратегии. Живой фронт, где действия каждого игрока — от рядового в окопе до офицера полка — влияют на исход войны.

### Референс: Foxhole
Мета-игра (живой фронт, логистика заводами и грузовиками, строительство траншей и фортификаций, руководство через ранги и полки) взята из **Foxhole** — это осознанная основа, а не совпадение. Камера — тоже как у Foxhole: изометрия сверху (решение и его цена — в [docs/design.md](docs/design.md), раздел 3). Мы делаем лучше за счёт того, чего в Foxhole нет:
- **Модульный конструктор оружия** — армия сама проектирует и утверждает модели, заводы выпускают именно их;
- **Кроссплатформа ПК + мобилки** в одной войне;
- **Обучение как допуск** — ранги и полки как в Foxhole (единого главнокомандующего нет), но инструменты (метки, операции, заказы заводам) открываются ещё и через курсы, а не только через договорённость в чате.

Открытые вопросы, на которые дизайн обязан ответить: как удержать масштаб фронта (Foxhole — сотни игроков на регион), как логистике работать при малом онлайне и чем мы отличаемся с первого скриншота. Подробно, вместе со справедливостью кроссплея ПК против мобилок, — в [docs/design.md](docs/design.md).

### Ключевые фичи
- Ранги за признание и полки (без единого главнокомандующего)
- Физическая логистика (оружие везут грузовиками на фронт)
- Конструктор оружия (модульная сборка из компонентов)
- Инженерные работы (траншеи, деформация меша, фортификации)
- Кроссплатформа (ПК + Мобилки)
- Low-Poly стиль

## Быстрый старт

### Требования
- Godot 4.7

### Запуск
1. Открой `project.godot` в Godot Editor
2. Нажми F5

### LAN (2-6 игроков)
1. Каждый вписывает **ник**. Один жмёт **Создать лобби** — оно само появляется у друзей в списке
2. Остальные выбирают игру в списке (или вводят IP вручную) и подключаются
3. Хост жмёт **Начать матч**. Выйти из лобби — **Покинуть лобби**
4. Firewall: UDP **7000** (игра) и **7001** (автопоиск) на машине хоста

Локальный тест без второй машины: Debug → Run Multiple Instances = 2.

## Управление

> Сейчас в сборке вид от первого лица. Камера меняется на изометрию сверху (фаза 1.5 [roadmap](docs/roadmap.md)): обзор мышью и свайпом уйдёт, направление стрельбы — курсор мыши, правый стик геймпада или правый стик на таче.

| Действие | ПК | Геймпад | Сенсор |
|---|---|---|---|
| Движение | WASD | Левый стик | Плавающий джойстик слева |
| Обзор | Мышь | Правый стик | Свайп по экрану / по FIRE |
| Огонь | ЛКМ | RT | FIRE (справа внизу, вокруг неё дугой DUCK/R/AIM/JUMP; дубль слева) |
| Прицел | ПКМ (удержание или нажатие — в настройках) | LT | AIM (переключатель) |
| Прыжок | Space | A | JUMP |
| Присед | Ctrl / C | B | DUCK (переключатель) |
| Спринт | Shift | L3 | Джойстик до упора вперёд |
| Перезарядка | R | X | R |
| Смена оружия | Колесо | LB / RB | — |
| Меню | Esc | Start | II / «Назад» |

Чувствительность, инверсия Y и режимы прицела/приседа — в меню паузы (сохраняются в `user://settings.cfg`).
